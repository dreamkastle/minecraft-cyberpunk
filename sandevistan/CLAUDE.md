# Sandevistan — Fabric-мод для Minecraft 26.3

Мод про имплант «Сандевистан» из Cyberpunk: Edgerunners. Пакет: `com.smi7i.sandevistan`, mod id: `sandevistan`.
Проект: `C:\mods\sandevistan`. Автор работает один и не программист: объясняй простыми словами, сам правь файлы, сам запускай сборку и сам исправляй ошибки компиляции.

## Окружение
- Minecraft 26.3 (в `fabric.mod.json` зависимость `>=26.2`), Fabric Loader >=0.20.1, Fabric Loom 1.19.4, Java 25.
- С 26.1 игра без обфускации: код пишется на официальных названиях Mojang (не Yarn). В `build.gradle` нет `mappings`, вместо `modImplementation` используется `implementation`.
- Структура: серверный/общий код в `src/main`, клиентский в `src/client` (`src/client/java`, `src/client/resources`).
- Внимание: в `gradle.properties` стоит `minecraft_version=26.2` (сборка и исходники идут под 26.2).
- Запуск: Gradle `runClient`. Сборка: `compileJava` и `compileClientJava`. Сразу в мир: `runClient --args="--quickPlaySingleplayer \"New World\""`.
- Sodium и Iris подключены только для тестового запуска (`localRuntime` из Modrinth maven в `build.gradle`, версии `sodium_version` / `iris_version` в `gradle.properties`; проверено 2026-11-09: Sodium 0.9.2, Iris 1.11.4, мир грузится без ошибок). Шейдерпаки кладутся в `run\shaderpacks`.
- Так же для теста подключены EMF 3.3.12 и ETF 7.2.7 (`emf_version`/`etf_version`) и ресурс-пак Fresh Animations: Player Extension 1.1.0 (`run\resourcepacks\FA+Player-v1.1.zip`, включён в `run\options.txt`). Мод должен работать и с ванильными анимациями, и с FA. Риски (2026-11-09, ждут проверки пользователем): EMF анимирует модели через свои mixin'ы в `LivingEntityRenderer`/`EntityRenderDispatcher` (`EMFStateStaticSnapshot`, ETF `ETFEntityRenderStateViaReference`) — послеобразы-снимки могут анимироваться «вживую» вместе с игроком; имплант на спине привязан к `model.body` (FA двигает тело по-своему).
- Пользователь проверил с FA: «всё работает», но послеобразы «шли на месте». Исправление: `client/compat/EmfCompat` (проверка `isModLoaded("entity_model_features")`) → `EmfCompatImpl` регистрирует `EMFAnimationApi.registerAnimationHook`; `onAnimationStart` возвращает false (= отменить анимацию EMF), если `context.activeState().vanillaState()` — `AfterimageRenderState`. EMF/ETF подключены `compileOnly` (в мод не попадают, игроку не обязательны). Ещё не проверено пользователем.
- Белые надписи над хотбаром (`sendOverlayMessage`: «остывает», «Перегрев…», «КИБЕРПСИХОЗ») убраны по просьбе пользователя — их заменяют голограммы, шкалы и окошко остывания. Не возвращать.
- По умолчанию в системе Java 21, а Loom требует 25. Перед gradlew в PowerShell: `$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-25.0.5.8-hotspot"`.
- Исходники Minecraft сгенерированы (`genSources`): `.gradle\loom-cache\minecraftMaven\net\minecraft\minecraft-clientOnly-*\26.2\*-sources.jar` и `minecraft-common-*`. Читать оттуда, а не по памяти.

## Правила для API 26.x (проверено на ошибках сборки)
Многое переименовано, старые туториалы по 1.20-1.21 не подходят:
- `ResourceLocation` -> `Identifier`.
- `PayloadTypeRegistry.playC2S()/playS2C()` -> `serverboundPlay()/clientboundPlay()`.
- `player.displayClientMessage(msg, true)` -> `player.sendOverlayMessage(msg)` (текст над хотбаром).
- `KeyBindingHelper.registerKeyBinding` -> `KeyMappingHelper.registerKeyMapping` (пакет `net.fabricmc.fabric.api.client.keymapping.v1`); клавиша `KeyMapping`, категория через `KeyMapping.Category.register(Identifier)`.
- `ClientTickEvents` лежит в `net.fabricmc.fabric.api.client.event.lifecycle.v1`.
- Открытый экран: `client.gui.screen()` вместо `client.screen`.
- HUD: `HudElementRegistry.attachElementBefore(VanillaHudElements.CHAT, id, (GuiGraphicsExtractor, DeltaTracker) -> ...)`.
- Отрисовка GUI: `GuiGraphicsExtractor`, методы вроде `extractRenderState` / `extractBackground` вместо старых `render*`.
- Mixin: `@Shadow` не находит поля и методы родительских классов (например `leftPos` в `AbstractContainerScreen`, `addSlot` в `AbstractContainerMenu`). Используй `@Accessor` / `@Invoker` на классе, где они объявлены. `@Shadow` работает только для членов самого целевого класса.
- Пост-эффекты (шейдеры на весь мир): JSON в `assets/<ns>/post_effect/<name>.json`, свой вершинный шейдер `assets/<ns>/shaders/post/fullscreen.vsh`. Значения uniform в JSON фиксированные. Подробный гайд по 26.3: https://github.com/carlodrift/minecraft-vanilla-shaders (docs/post-effects.md).
- Если пост-эффект не компилируется, игра в процессе работы отключает все ресурспаки и пишет причину в лог.

## Как работать
- Сначала прочитай существующий код, потом меняй. Не создавай дубликаты файлов.
- После каждого изменения запускай сборку (`compileJava`, `compileClientJava`) и исправляй ошибки.
- Новые Mojang-API проверяй по исходникам в IDEA или по документации https://docs.fabricmc.net/26.1.2/ , а не по памяти.
- По итогам этапа объясняй пользователю простыми словами, что проверить в игре.
